# Kapitelweise – Buchsuche

Dieser Service verbindet Kapitelweise mit Open Library (openlibrary.org), einer freien Datenbank mit Millionen Büchern.

- Bücher nach Titel oder Autor suchen.
- Vorgeschlagene ISBNs prüfen: Gibt es das Buch, kommen Titel, Autor und Seitenzahl zurück. Gibt es es nicht, wird der Vorschlag abgelehnt.
- Gefundene Bücher werden zehn Minuten lang zwischengespeichert. Wer ein Buch sucht und es gleich danach vorschlägt, muss deshalb nicht noch einmal auf Open Library warten.

Online: https://kapitelweise-bookapi-38e6cb97d9cf.herokuapp.com
